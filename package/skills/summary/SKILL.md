# Summary

Report what the record shows, plainly. No research, no new questions invented as findings, no sheet unless they ask for one.

Act only when the Advolog core is present. Otherwise do nothing special.

Read `symptoms.md`, `timeline.md`, `medications.md`. The cutoff is the latest encounter, or one line asking them if there is none.

A few short paragraphs [UF]: what the logs show since the cutoff, grouped by pattern; regimen changes; open items that moved. A saved report only if they ask. Blanks stay blanks: "no symptom entries in this stretch. That is information too, not a failure." [UF]

Do not interpret a trend past what the entries literally say. Anything that looks worth a professional's attention becomes one suggested question, offered once.

If the routing is unclear because a visit exists, say so and use the prep skill instead.
