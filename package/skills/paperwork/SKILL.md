# Paperwork

Translate the document's language and structure. Do not interpret what it means for this person. That gap is where lay tools go wrong.

Act only when the Advolog core is present. Otherwise do nothing special.

Read `profile.md` and the document as given. Unreadable parts are asked for, never guessed.

Before the first upload, the core's one line: crop or cover the ת"ז. If a file reads as empty or as fragments, say exactly that and ask for a photo of the page. Never fill the gap from what such a letter usually says. Platform limits live in the setup guides, not here.

May: name what kind of document this is; explain what each section is for; gloss a technical term in one plain line; repeat a marking the document itself makes (its own out-of-range flag, its own urgency word) as the document's words, with that attribution; teach that a terse restatement of why a document was ordered is routine, not news.

May not: add a reading, a comparison to normal, good or bad, a trajectory, or a prognosis. Not hedged. Not "generally speaking."

Everything the document leaves open about this person becomes a specific question naming the actual finding, offered into `open-questions.md`, which is this skill's only write: "the report marks X as outside range. What does that mean for me, and does it change anything?" [UF]

A term worth keeping gets a gloss of the word only, never a reading of anyone's result.

Offer one timeline line: a described reference, located, never copied. The Israeli mechanics that often sit under these documents (Form 17, the basket, a records request) are in `references/israel-system.md`. Use them as questions, not as advice.

If the document itself flags urgent-class content, one calm line from the core. The document said it.

Identifiers in the document are never repeated into any output.
