# התקנה ב־Claude — מדריך מלא

יש שתי דרכים טובות להריץ את Advolog ב־Claude. לא צריך לבחור מראש נכון: אפשר להתחיל בקלה ולעבור אחר כך, הרשומות עוברות איתך.

**דרך א — פרויקט באתר (claude.ai):** מתאימה לכולם, עובדת גם בנייד. השיחה מכינה כל שמירה בשבילך, קובץ אחד בכל פעם, או שהלוח שומר בשבילך.
**דרך ב — שהעוזר יקים בשבילך (Claude Code / Cowork):** הפשוטה ביותר — מדביקים שורה אחת, והעוזר מחלץ, מקים ומתחיל את הריאיון. העוזרת כותבת את הרשומות ישירות לתיקייה בעצמה — הכי חלק שיש.

---

## דרך א — פרויקט ב־claude.ai

1. נכנסים ל־claude.ai ומתחברים לחשבון (חינמי מספיק להתחלה).
2. בתפריט הצד: **Projects** ← **New project**. שם חופשי — למשל «התיק הרפואי שלי».
3. פותחים את חלון ההגדרות של הפרויקט ומאתרים את אזור ההנחיות (Instructions / הוראות פרויקט).
4. מדביקים שם את כל התוכן של `package/prompts/core-map.md`.
5. באזור הקבצים של הפרויקט (Project knowledge) מעלים את הקבצים מ־`package/prompts/skills/` ואת `package/he/` (שלושת הקבצים). אפשר לגרור את כולם יחד.
6. פותחים שיחה חדשה בתוך הפרויקט וכותבים שלום — או פשוט מתחילים לספר. זהו. הריאיון יוביל משם, שאלה אחת בכל פעם.

**חלופה בלי שום התקנה:** לא רוצים פרויקט? פותחים שיחה רגילה ומדביקים את פרומפט הפתיחה מ־`package/starter/starter-prompt.md` (או מכפתור ההעתקה באתר). זו גרסה קלה ושלמה — בלי קבצים בכלל.

**איפה הרשומות?** בדרך הזאת קובצי הרשומות נשמרים אצלך במחשב, בתיקייה אחת שאת/ה בוחר/ת, והשיחה מלווה כל שמירה — או שפותחים את `dashboard.html` מתוך אותה תיקייה והוא מכניס את העדכונים בלחיצה (המדריך המלא: `dashboard-guide.md`). בנייד, כשאין תיקייה נוחה, אפשר לנהל את הגרעין בתוך השיחה ולהעביר לקבצים כשמגיעים למחשב.

## דרך ב — שהעוזר יקים בשבילך (Claude Code / Cowork)

הדרך הפשוטה ביותר. מורידים את קובץ ה־zip, ומדביקים שורה אחת — והעוזר עושה את כל השאר: מחלץ, מקים ומתחיל את הריאיון.

1. מתקינים את אפליקציית Claude למחשב (או את Claude Code) ומתחברים.
2. מורידים את חבילת ה־zip ומשאירים אותה בתיקיית ההורדות — אין צורך לחלץ בעצמך.
3. פותחים שיחה ב־Claude Code או ב־Cowork ומדביקים את השורה:

   > מצא/י את הקובץ advolog.zip בתיקיית ההורדות, חלץ/י אותו לתיקייה חדשה, ואז קרא/י את הקובץ CLAUDE.md שבתוכה ופעל/י לפיו — הקם/י לי את הכלי ולווה/י אותי צעד־צעד בריאיון הפתיחה.

העוזר מחלץ, קורא את המפה בעצמו, ומתחיל את הריאיון — ומהרגע הזה שומר את הרשומות ישירות בתיקייה, כל שמירה בשורה רגועה אחת.

**מעדיפים ידנית?** מחלצים את ה־zip (לחיצה ימנית ← «חלץ הכול» בווינדוס, לחיצה כפולה במק), שמים את תיקיית `package` איפה שנוח — אפשר לשנות לה שם — ופותחים אותה ב־Claude (Open folder). העוזרת קוראת את המפה משם בעצמה.

**יחידות מיומנות:** בסביבה הזאת אפשר גם «להתקין» יחידות כך שיופעלו אוטומטית. אין צורך לעשות את זה מראש: כשיחידה תהיה רלוונטית, העוזרת תציע ותלווה את ההתקנה צעד־צעד, ותוודא כל צעד לפני הבא.

## איזה מודל, ובאיזה מאמץ

שורה אחת לכל סוג עבודה:

- **רישום יומיומי** (צ׳ק־אין, רישום אירוע, קליטה): **Sonnet · Medium**. Medium היא ברירת המחדל באפליקציה — לא צריך לגעת בכלום.
- **הכנה לביקור וסיכומים** (דף הכנה, טבלת תרופות, סיכום תקופה): **Sonnet · High**. בתוכנית בתשלום אפשר גם Opus.

איך משנים: לוחצים על שם המודל ליד כפתור השליחה ← **Effort** ← בוחרים רמה. אם האפשרות לא מופיעה אצלך, ממשיכים עם מה שיש — הכול עובד גם כך. (שמות המודלים והרמות מתחלפים; נבדק מול דפי העזרה של Claude ב־1.10.2026.)

## העלאת מסמכים וצילומים

- **לפני כל העלאה: חותכים או מכסים את מספר תעודת הזהות.** הכי פשוט — הצנזור החזותי שבלוח (`dashboard.html`), או פס נייר על המספר לפני שמצלמים. הכלי ממילא לא צריך את המספר, ואין סיבה שיישב בחשבון.
- **PDF סרוק נקרא במלואו עד 100 עמודים.** בקובץ עד 100 עמודים Claude קורא גם את הטקסט וגם את מה שמופיע כתמונה — ולכן גם מכתב שחרור סרוק. בקובץ ארוך יותר (עד 1,000 עמודים) נקרא הטקסט בלבד; מסמך סרוק ארוך כדאי לפצל.

## קובץ להגיש לרופא/ה — Claude Docs

בתוכניות Pro ו־Max (התכונה בבטא, ואינה כלולה בתוכנית החינמית), דף ההכנה לביקור וטבלת התרופות נוצרים כ־**Doc**: מסמך שנפתח לצד השיחה, וממנו מייצאים קובץ: בכפתור **Export** בוחרים Word או PDF. כך מגישים לרופא/ה קובץ, לא צילום מסך של שיחה.

שורה אחת שחשוב לדעת: **ה־Doc פרטי עד שמשתפים אותו — וקישור שיתוף נמצא במרחק לחיצה אחת.** מי שמחזיק בקישור ומחובר לחשבון Claude יכול לפתוח את המסמך. לרופא/ה פשוט ובטוח יותר לייצא קובץ ולהגיש אותו; ולפני כל שיתוף — רשימת הבדיקה.

בנייד אפשר לצפות ב־Doc, אבל לא לערוך אותו ולא לשנות את הגדרות השיתוף. בתוכנית החינמית הדף נמסר כמו עד היום: קובץ מלא אחד לשמירה בתיקיית `reports` ולהדפסה.

## שיחה חדשה בתוך הפרויקט (לרגע שהעוזרת מציעה «שיחה חדשה»)

אחרי רישום, או אחרי שתיים־שלוש משימות, העוזרת תציע לפתוח שיחה חדשה. הסיבה, בשורה אחת: שיחות ארוכות נעשות כבדות — בשלב מסוים Claude מסכם מעצמו את החלקים המוקדמים, או שהשיחה מגיעה למגבלת האורך שלה, וכך או כך פרטים מתחילים להישמט. **שום דבר לא הולך לאיבוד: הרשומות שלך בקבצים, לא בשיחה.** לפני המעבר העוזרת כותבת פתק מסירה קצר, והשיחה הבאה קוראת אותו ראשון.

- **באתר:** נכנסים לפרויקט (Projects ← השם שבחרת) ← **New chat** בתוך הפרויקט. השיחה החדשה מכירה את ההנחיות והקבצים של הפרויקט. את פתק המסירה מקבלים כבלוק אחד להעתקה — ומדביקים אותו כהודעה הראשונה.
- **במחשב:** שיחה חדשה על אותה תיקייה. הפתק נשמר שם כקובץ `handoff.md`, והעוזרת קוראת אותו ואת הרשומות לבד.
- בשני המקרים, מילה אחת מספיקה בפתיחה: «תתעדכני» — והיא תספר איפה עמדנו.

## הערה חשובה על «זיכרון» (Memory)

גם ל־Claude יש זיכרון חוצה־שיחות, והוא **פועל כברירת מחדל** — גם בתוכנית החינמית. לרשומה רפואית עדיף מקור אמת אחד: הקבצים שלך. מה שכדאי לדעת:

- **לכל פרויקט זיכרון נפרד.** מה שנאמר בפרויקט של התיק הרפואי נשמר בזיכרון של אותו פרויקט, בנפרד מפרויקטים אחרים ומשיחות שמחוץ לפרויקטים.
- **בריאות, ונושאים רגישים אחרים, לא נכנסים לזיכרון כברירת מחדל.** ב־Settings ← Memory יש מתג בשם **«Include sensitive topics in memory»**. ההמלצה שלנו: **להשאיר אותו כבוי.** הקבצים שלך הם הרשומה, וזיכרון סמוי לא צריך להיות רשומה שנייה.
- **למלווים, במילים פשוטות:** מי שמדליק את המתג הזה מאפשר ל־Claude לשמור בזיכרון את האבחנה והתרופות של קרוב המשפחה. בשיחות רגילות, מחוץ לפרויקט, הזיכרון הזה מלווה כל שיחה בחשבון — גם שיחות שאין להן שום קשר לתיק. זה מידע של אדם אחר; עדיף שיישאר בקבצים.
- **שיחות אינקוגניטו (Incognito) אינן זמינות בתוך פרויקטים** — רק בשיחות שמחוץ לפרויקט — ולכן הן לא הפתרון לעבודה על התיק. רוצים שיחה אחת בלי זיכרון? בשיחה חדשה, לפני ההודעה הראשונה: «+» ← מכבים **Memory**. ואפשר להשהות את הזיכרון כולו ב־Settings ← Memory.

(שמות המסכים משתנים מדי פעם; אם לא מוצאים, מחפשים «memory» בהגדרות.)

## פרטיות בחשבון Claude — הליך קצר

ההצעה לעבור על זה מגיעה כבר בהתקנה, וחוזרת פעם אחת לפני הייצוא הראשון. שתי דקות:

1. נכנסים להגדרות החשבון (Settings) ← מחפשים את אזור הפרטיות או Data.
2. **שימוש בשיחות לאימון המודל:** אם מופיעה בחשבון שלך אפשרות כזו — מחליטים בה במודע. מי שמעדיף שהשיחות לא ישמשו לאימון, מכבה אותה. בחלק מסוגי החשבונות ברירת המחדל שונה, והמסכים משתנים מדי פעם — אם ההגדרה לא במקום המתואר, לחפש «privacy» או «data» בהגדרות. המדריך הזה מנחה ולא מבטיח: מה שקובע הוא מה שמופיע אצלך.
3. שווה להכיר גם את משך שמירת השיחות ואת אפשרות המחיקה — לפי מדיניות הפלטפורמה כפי שמוצגת בחשבון.
4. תזכורת קבועה, בלי קשר להגדרות: הכלי לעולם לא מבקש תעודת זהות, כתובת מדויקת או שם מלא מעבר למה שבחרת לרשום — וכל ייצוא עובר קודם את רשימת הבדיקה.

## עוד שני דברים, בשורה אחת

- **חיבורי נתוני בריאות (Health)** ב־Claude זמינים כרגע רק בארצות הברית, ולכן אינם רלוונטיים בישראל. Advolog לא נשען עליהם: הרשומה היא הקבצים שלך.
- **הכתבה קולית:** איננו מבטיחים הכתבה בעברית — עברית אינה ברשימת שפות ההכתבה ש־Claude מפרסם. מקלידים, והכול עובד.

## מתכוני אוטומציה (שכבה מתחלפת — לבדוק מדי פעם)

> **הסימון הזה חשוב:** תכונות תזמון של פלטפורמות הן החלק הכי פחות יציב בחבילה. המתכונים כאן נבדקים מחדש במחזוריות, וכל בדיקה עומדת גם **כפרומפט להדבקה** שעושה בדיוק את אותו הדבר, בלי שום תלות בתכונה. ההדבקה היא המסלול המובטח; התזמון הוא נוחות.

כל אוטומציה מוצעת בשיחה בכרטיס ברור (מה היא עושה, מה קוראת, מה כותבת, איך מכבים) ולא קיימת בלי הסכמה מפורשת. הפלט תמיד נוחת בתיבת הקליטה כהצעה — שום דבר לא נכנס לרשומות בלי אישור.

- **סריקת מחקר וקהילות** — פרומפט להדבקה: `package/prompts/twins/sweep-twin.md`. תזמון: אם בסביבת Claude שלך יש תכונת משימות מתוזמנות, יוצרים משימה חודשית שמדביקה את הפרומפט. אין תכונה כזו בחשבון? מדביקים את הפרומפט ידנית פעם בחודש — אותה תוצאה בדיוק.
- **בדיקת טריות התיקייה** — פרומפט להדבקה: `package/prompts/twins/freshness-twin.md`. בדרך ב זה קורה ממילא בכל «תתעדכני»; התזמון מיותר לרוב.
- **בדיקת יכולות ועדכוני הכלי** — פרומפט להדבקה: `package/prompts/twins/capabilities-twin.md`. כללי המקורות קשיחים (תיעוד רשמי בלבד), ו«אין חדש החודש» היא תשובה שלמה. אם יצאה גרסה חדשה של Advolog, הבדיקה גם סוקרת אותה בשבילכם: מפרטת כל שיפור במילים פשוטות ובמה הוא יכול לעזור לכם, נותנת לבחור מה לאמץ (אחד, כמה או כלום), ומבצעת רק את מה שבחרתם — צעד־צעד, גיבוי קודם, בלי לאבד דבר מהרשומות (הסכימות רק מוסיפות, לא מאפסות; ההיסטוריה, השאלות והתרופות נשארות כמו שהן).
- **סיכום סשן / מסירה** — פרומפט להדבקה: `package/prompts/twins/wrapup-twin.md`; מופעל ידנית בסוף ישיבה, בכל רגע שרוצים. העוזרת מציעה את אותו הדבר מעצמה אחרי רישום או אחרי כמה משימות (יחידת המסירה).
