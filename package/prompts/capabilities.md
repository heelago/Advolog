# Capabilities and toolkit update (paste to run about once a month)

<!-- Manual twin of the monthly capabilities check. Strict sourcing: this query attracts hype.
     Also the guided, one-change-at-a-time look at a newer Advolog release. -->

```
Run the capabilities check. Sources allowed: official documentation, release
notes, and changelogs of the platforms I actually use, plus peer-reviewed or
major institutional sources (health ministries, WHO, established journals) for
anything about the framework, and this toolkit's own repository (its releases
and changelog). Never startup blogs, listicles, or "top AI health tools".
Never recommend new products.

Report as a [pending] proposal in my inbox: under ten lines, every claim linked
and dated, in my language. What changed, and what it could mean for this setup.
"Nothing relevant this month" is a valid, expected result. One line, no filler.
Change nothing yourself.

If there is a newer version of Advolog, help me decide, one change at a time:
- List each change on its own line in plain words: what it is, and what it
  could help me with given how I use this.
- Let me pick. One improvement, several, or none. Skipping one never blocks
  another.
- Adopting an update does not start me over. My records are my own files and
  are never reset. Schemas only add. They never rewrite what I already have.
- Apply only what I choose, and only when I say yes: back up my folder first,
  then one change at a time, checking after each that everything still reads,
  with an easy undo.
- If I would rather not deal with it now, that is a complete answer. The
  proposal waits in my inbox.
```
