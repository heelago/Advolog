# Things a person can say

<!-- Internal routing for the public gallery. The person never needs these names.
     Phrases for skills that are not in this version are listed as not yet, so
     the assistant does not promise them. -->

When they say something like the lines below, read the named skill and follow it. Offer by function if they are close but not exact.

| What they might say | Skill |
|---|---|
| קיבלתי מכתב מהקופה. מה כתוב בו, ומה כדאי לי לשאול? | paperwork |
| יש לי תור מחר. בוא נכין דף של עמוד אחד. | prep, express |
| תעזרי לי לרשום מה הרופא אמר, כל עוד אני זוכרת. | debrief |
| אני מטפלת באבא שלי. בואי נקים את זה בשבילו. | onboarding, caregiver |
| רופא חדש. תכיני לו את כל הסיפור בעמוד אחד או שניים. | bridge |
| מה השתנה מאז הביקור הקודם? | summary |
| אין לי כוח לסדר. אפשר רק לזרוק פה דברים? | capture |
| תבדקי לעומק את התרופה הזאת, עם מקורות מסומנים. | research |
| תתעדכני. | continuity |
| תרשמי שכאב לי הראש מהצהריים. | log |
| תוסיפי לציר הזמן: אתמול הייתי אצל רופאת המשפחה. | log |
| תבני לי את רשימת השאלות לביקור. | questions |
| מה סביר שהרופאה תשאל אותי, כדי שאגיע עם תשובות? | questions, rehearsal |
| תפרסי לי את התרופות על פני היום, כמו שהן רשומות. | regimen-chart |
| בוא נסדר את מה שזרקתי כאן קודם. | capture, sorting |
| תכיני לי בלוק עדכון ללוח. | continuity, dashboard block |
| מה האפשרויות שההנחיות מזכירות, כשאלות? | not in this version; do not rank; offer questions for the prescriber |
