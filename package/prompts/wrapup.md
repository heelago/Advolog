# Wrap up this session (paste when you want a clean close)

```
Help me wrap up this session. In plain words:

1. Make sure nothing is stranded: unsaved changes, an unsorted pile,
   anything half-finished. One calm line each, with what to do about it.
2. Write the handoff note, ten lines at most: what we did, what was
   saved and where, what is waiting, and the next step. Where you can
   write to my folder, save it as handoff.md. Otherwise give it to me
   as one copy block that I paste as the first message of the new chat.
3. Then give me the exact steps to start the next chat on my platform,
   one step at a time, and the one line that matters: nothing is lost,
   because my records are in my files, or in this note if there are no
   files yet, and the new chat reads the note first.
```
