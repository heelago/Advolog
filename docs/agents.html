עוזר אישיA personal agent

החבילה אחת. העוזרת מסתכלת מה באמת יש אצלכם, ומובילה אל ההקמה הכי מתאימה שאפשר באמת להשתמש בה. יש רק כן אחד, והוא מוריד את החבילה הציבורית. שום דבר לא נשלח. הרשומה היא קבצים אצלכם. One package. The assistant looks at what you actually have, and guides you to the best setup you can use. There is only one yes, and it downloads the public package. Nothing is sent. The record is files you keep.

הסדר: תיקייה, אם יש גישה. אחרת פרויקט Claude, והמתאם כבוי. אחרת פרויקט ChatGPT, עם זיכרון של הפרויקט בלבד. אם כבר נמצאים ב־Dot או ב־Grok Bot, נשארים שם. בלי כל אלה, שיחה רגילה. Duet אינו מסלול: הוא זמין בארצות הברית בלבד, נבדק 11.11.2026. אם המסך שונה, המסך קובע. The order: a folder, if one can be opened. Otherwise a Claude Project, with the coordinator off. Otherwise a ChatGPT project, with project-only memory. If you are already in Dot or Grok Bot, stay there. Without any of those, a plain chat. Duet is not a path: it is available in the United States only, checked 11.11.2026. If the screen differs, the screen wins.

פרויקט ClaudeA Claude Project

שיחה ראשית אחת. הקבצים מחזיקים את ההנחיות, את המודולים, ואת my-record.md. One main chat. The files hold the instructions, the modules, and my-record.md.

  1. ביצירה, נבדק 26.11.2026: מכבים את Project coordinator. דלוק פותח פרויקט מסוג Claude Code. כבוי נותן פרויקט רגיל. חוט צד נפתח לבד רק אם המתג נשאר דלוק.When creating it, checked 26.11.2026: turn Project coordinator off. On opens a Claude Code style project. Off gives a normal project. A side thread starts on its own only if the switch is left on.
  2. ההנחיות, נבדק 26.11.2026: על דף הפרויקט, הוספה ואז עריכה. אם המסך מראה את הנתיב מ־23.11.2026, זה הגיבוי: גלגל השיניים, ואז הזיכרון.Instructions, checked 26.11.2026: on the project page, Add then Edit. If the screen shows the 23.11.2026 path, that is the fallback: the gear, then Memory.
  3. זיכרון: Use account memory נצפה דלוק ב־26.11.2026 בחשבון אחד. לרשומה רפואית כדאי לשקול לכבות. נושאי בריאות לא נשמרים כברירת מחדל.Memory: Use account memory was observed on, on one account, on 26.11.2026. For a medical record, consider turning it off. Health topics are not saved by default.
  4. סיכום חודשי, Reflect: כשהזיכרון דלוק, Claude מסכם את נושאי השיחות. הסיכומים השמורים נשארים עד Delete stored reflections בעמוד Reflect. שיחות בסתר, ושיחות עם חיבור בריאות, לא נכנסות. נקרא 26.11.2026.Monthly recap, Reflect: when memory is on, Claude summarizes chat topics. Stored reflections stay until Delete stored reflections on the Reflect page. Incognito chats, and chats that use a health integration, are left out. Read 26.11.2026. המקורSource
  5. פרטיות: Settings, Privacy, מכבים את Help Improve our AI models. נבדק 26.11.2026.Privacy: Settings, Privacy, turn off Help Improve our AI models. Checked 26.11.2026.

בדיקה תקופתית היא טקסט מתוך החבילה, איפה שהמסך מציע משימה מתוזמנת. אין חיבור לדוא"ל בשביל הרשומה. A checkup is text from the package, where the screen offers a scheduled task. Do not connect email for the record.

פרויקט ChatGPTA ChatGPT project

פרויקט פרטי. מדביקים את ההנחיות, מעלים קובץ, מצרפים את הרשומה, ורק אז שיחה חדשה בתוך הפרויקט. A private project. Paste the instructions, upload a file, attach the record, and only then open a new chat inside the project.

זיכרון של הפרויקט בלבד, נבדק 26.11.2026: שלוש הנקודות, Project settings, תחת Memory. זה יכול לקחת כמה שעות. Project-only memory, checked 26.11.2026: the three dots, Project settings, under Memory. It may take a few hours.

OpenAI כותבת, בדף שנקרא ב־26.11.2026: למידע של מישהו אחר, חשבון נפרד או פרויקט נפרד עם זיכרון של הפרויקט בלבד. זה מתאים להקמה כאן, ולתיעוד עבור מישהו קרוב, רק בהסכמה. Health עצמו זמין בארצות הברית, לא בישראל. כשהזיכרון דלוק, שיחות Health יכולות ליצור זיכרונות לשיחות הבאות. הילה, 19.11.2026. OpenAI writes, on the page read on 26.11.2026: for someone else's information, a separate account or a separate project with project-only memory. That matches this setup, and keeping a record for someone close, only with consent. Health itself is available in the United States, not in Israel. When memory is on, Health chats can create memories for later chats. Heela, 19.11.2026. המקורSource

פרטיות: מכבים את Improve the model for everyone, תחת Data controls. בחשבון אישי הוא דלוק כברירת מחדל. נבדק 26.11.2026. Privacy: turn off Improve the model for everyone, under Data controls. On a personal account it is on by default. Checked 26.11.2026.

DotDot

אותו מתג של ChatGPT חל גם על השיחות, הפעולות, והאוטומציות. ל־dot זיכרון משלו שנשאר דלוק גם כשהזיכרון של ChatGPT כבוי, ואי אפשר למחוק ממנו פריט אחד. לא מספרים לו פרטי בריאות שלא היו רוצים שיישארו. לא מחברים דוא"ל בשביל הרשומה. נקרא 26.11.2026. The same ChatGPT setting also covers conversations, actions, and automations. A dot has its own memory that stays on when ChatGPT's memory is off, and a single item cannot be deleted. Do not tell it health details you would not want kept. Do not connect email for the record. Read 26.11.2026.

Grok BotGrok Bot

האימון נקבע לפי הגדרות הפרטיות של חשבון Cursor. לא נמצא דף רשמי שאומר בפשטות מה קורה בחשבון אישי, ולכן לא מכניסים פרטי בריאות עד תשובה ברורה מהתמיכה. אין מסך זיכרון: שואלים מה הוא זוכר, ומבקשים שישכח. איפוס שיחה לא מוחק את הזיכרון. מחיקת הבוט כן. כל הבוטים חולקים מחשב אחד. נקרא 26.11.2026. Training follows the Cursor account's privacy settings. No official page says plainly what happens on a personal account, so keep health details out until support gives a clear answer. There is no memory screen: ask what it remembers, and ask it to forget. Resetting a conversation does not erase memory. Deleting the Bot does. All bots share one computer. Read 26.11.2026. המקורSource

Claude Code, או סוכן עם תיקייהClaude Code, or a folder agent

Claude Code קורא את CLAUDE.md. Codex קורא את AGENTS.md. שניהם שולחים אל core.md קודם. התיקייה היא ההקמה, והרשומה יושבת לידה, לא בתיקייה משותפת. אחרי הורדה פותחים מחדש את package/. בדיקה תקופתית היא קובץ מ־prompts/, או משימה מתוזמנת אם המסך מציע אחת. Claude Code reads CLAUDE.md. Codex reads AGENTS.md. Both send you to core.md first. The folder is the setup, and the record sits beside it, not in a shared folder. After a download, reopen package/. A checkup is a file from prompts/, or a scheduled task if the screen offers one.

שיחה רגילהA plain chat

בלי פרויקט ובלי תיקייה: מדביקים את ההנחיות, עד 7,000 תווים, ומעלים קובץ אחד. שומרים my-record.md בסוף. פרטי בריאות מחוץ לזיכרון. With no project and no folder: paste the instructions, at most 7,000 characters, and upload one file. Save my-record.md at the end. Keep health details out of memory.
