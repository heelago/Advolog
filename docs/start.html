עשר הדקות הראשונותThe first ten minutes

הספירה בדקות היא לפי התכנון, לא לפי שעון. אל תצטטו אותה כמדידה. לחיצות הפרויקט נבדקו פעם אחת, ב־23.11.2026, בחשבון אחד. The minute counts are as designed, not from a clock. Do not quote them as a measurement. The project clicks were checked once, on 23.11.2026, on one account.

  1. בודקים: ביטול אימון אם יש מתג, בריאות מחוץ לזיכרון, גישה לאינטרנט, יצירת קבצים.Check: training off if the switch exists, health out of memory, web access, file creation.

  3. העוזרת מסבירה שזו חבילה ולא אתר, אומרת מה באמת על המסך, ושואלת כן אחד. כן הזה רק מוריד את החבילה הציבורית. אין שאלה שנייה. כן הזה אינו הסכמה לשום דבר אחר. שום דבר לא נשלח.The assistant explains that this is a package and not a site, says what is actually on the screen, and asks for one yes. That yes only downloads the public package. There is no second question. That yes is not consent for anything else. Nothing is sent.
  4. ביצירת פרויקט מומלץ לכבות את Project coordinator. הוא דלוק כברירת מחדל ופותח פרויקט מסוג Claude Code. כבוי נותן פרויקט רגיל. חוט צד נפתח לבד רק אם המתג נשאר דלוק. גם Use account memory דלוק כברירת מחדל. לרשומה רפואית כדאי לשקול לכבות. בדקו את המסך. אחר כך בודקים איפה הקבצים נחתו. אם זו לא תיקייה אצלכם, מורידים עותק. ההנחיות, נבדק 26.11.2026: על דף הפרויקט, Add ואז Edit, והשדה Project instructions. אם המסך עדיין מראה גלגל שיניים ולשונית Memory, זה הנתיב מ־23.11.2026. הקבצים דרך Add context. נשארים באותה שיחה. שם הקובץ הוא בדיוק my-record.md. אם נוספה קידומת, משנים. הורדה: בחשבון שנבדק התפריט היה מוסתר. הסרה מההקשר: לחיצה ימנית. בדקו את המסך. אם עדיין יש שדה הנחיות: מדביקים, מעלים קובץ אחד, מצרפים את my-record.md, ופותחים שיחה חדשה. בתיקייה במחשב פותחים מחדש את package/.When you create a project, turn Project coordinator off. It is on by default and opens a Claude Code style project. Off gives a normal project. A side thread starts on its own only if that switch stays on. Use account memory is also on by default. For a medical project, consider turning it off. Check the screen. Then check where the files landed. If it is not a folder you keep, download a copy. The instructions, checked 26.11.2026: on the project page, Add then Edit, then Project instructions. If the screen still shows a gear and a Memory tab, that is the 23.11.2026 path. Files go through Add context. Stay in that same chat. The file is named exactly my-record.md. If a prefix was added, rename it. Downloading: on the account that was checked, the menu was hidden. There is one question about downloading. The instruction is under 10,000 characters. A new project dialog has a Project coordinator - Beta switch, on by default. The test ran with it on. גיבוי, בלי אינטרנט או בלי יצירת קבציםFallback, no web access or no file creation

אומרים את זה במפורש. מדביקים את ההנחיות, עד 7,000 תווים, ומעלים קובץ אחד. בטלפון, אם האפליקציה לא יוצרת קבצים, נשארים עם טקסט ההתחלה בלי הורדה, ושומרים my-record.md אחד בסוף. Say so plainly. Paste the instructions, at most 7,000 characters, and upload one file. On a phone, if the app cannot create files, stay with the starting text and no download, and save one my-record.md at the end.
