הדרך הראשית, ClaudeThe primary path, Claude

  1. בודקים: ביטול אימון אם יש מתג, בריאות מחוץ לזיכרון, גישה לאינטרנט, יצירת קבצים.Check: training off if the switch exists, health out of memory, web access, file creation.
  2. מעתיקים את הנחיית ההקמה מדף הבית, בעברית. יש כפתור לאנגלית.Copy the setup instruction from the home page, in Hebrew. There is a button for English.
  3. העוזרת מסבירה שזו חבילה ולא אתר, ובודקת מה באמת על המסך: פרויקט Claude, פרויקט עם שדה הנחיות, או עוזר אחר אם הוא שם. היא ממתינה לפני שהיא ממשיכה. רק כן מוריד את החבילה הציבורית. כן הזה אינו הסכמה לשום דבר אחר. שום דבר לא נשלח.The assistant explains that this is a package and not a site, and checks what is actually on the screen: a Claude Project, a project with an Instructions field, or another agent if it is there. It waits before it continues. Only a yes downloads the public package. That yes is not consent for anything else. Nothing is sent.
  4. בודקים איפה הקבצים נחתו. אם זו לא תיקייה אצלכם, מורידים עותק. ואז שומרים את ההנחיות במקום שההקמה שנבחרה שומרת אותן. בפרויקט Claude: הנחיות הפרויקט, הקבצים ב־Context, ונשארים בשיחה הראשית. אם עדיין יש שדה הנחיות: מדביקים, מעלים קובץ אחד, מצרפים את my-record.md, ופותחים שיחה חדשה. בתיקייה במחשב פותחים מחדש את package/.Check where the files landed. If it is not a folder you keep, download a copy. Then save the instructions where the chosen setup keeps them. On a Claude Project: Project instructions, the files in Context, and stay in the main conversation. If an Instructions field is still there: paste, upload one file, attach my-record.md, and open a new chat. For a folder on a computer, reopen package/.

עד השאלה אם להוריד, לפי התכנון, ולא לפי ריצה חיה. ההנחיה קצרה מ־10,000 תווים. Up to the download question, as designed, and not from a live run. The instruction is under 10,000 characters.

גיבוי, בלי אינטרנט או בלי יצירת קבציםFallback, no web access or no file creation

אומרים את זה במפורש. מדביקים את ההנחיות, עד 7,000 תווים, ומעלים קובץ אחד. בטלפון, אם האפליקציה לא יוצרת קבצים, נשארים עם טקסט ההתחלה בלי הורדה, ושומרים my-record.md אחד בסוף. Say so plainly. Paste the instructions, at most 7,000 characters, and upload one file. On a phone, if the app cannot create files, stay with the starting text and no download, and save one my-record.md at the end.
