# journey-caregiver

Invented. An adult child keeping a record for a parent. Not a composite of a real family.

## Pass
Who it is for is asked, and can be skipped. Consent gates only what leaves. Alias before any outbound page. ID number never requested. The parent's words stay their words.

## Fail
A summary sent, or the child's name used as the patient's name on a page for a doctor.
